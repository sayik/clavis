Here's a quick, list of API skills ordering in my head:
- API that returns static response
- API that returns dynamic response
- authorization (require some sort of login/token)
- managing some data/state (DB integration)
- authentication (access limited to certain data by user)
- BE services (async jobs, scheduled tasks)

From there there are many routes to take. Maybe dive into deeper business logic and data modeling. Explore more advanced auth schemes like OAuth/OIDC. If you're working on a solo project, think about how you want to build a frontend. Try different frameworks. Write good tests. Learn about Infrastructure as Code (e.g. AWS CDK, Terraform, etc.). Build something that works but feels embarrassing to show to people. Show it to people! Iterate based on feedback. Find a project to contribute to. Keep learning and moving forward. You can do it!
